The default tools now come with the app, so a new install is ready without downloading them, and starting up no longer checks every tool online. Removing one from the `tools` option removes it on the next start. The terminal finds your tools again, and gets a Starship prompt, `eza`, `zoxide`, tab completion that cycles and history search, with `starship`, `eza` and `zoxide` added to the default list: add them to your `tools` option to use them. Git comes with sensible defaults, new repositories start on `main`, Neovim is the editor, and once you've signed in with `gh auth login` your Git name and email are filled in from GitHub.
